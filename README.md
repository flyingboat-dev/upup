# @flyingboat/upup

CLI tool to check dependency versions in a project and show which ones are outdated.

## Install (global)

```
npm install -g @flyingboat/upup
pnpm add -g @flyingboat/upup
```

Via npx:
```
npx @flyingboat/upup
pnpm dlx @flyingboat/upup
```

## Usage

Run in the current project:

```
upup
```

for CICD

```
upup --ci
```
